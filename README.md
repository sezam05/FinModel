# Финансовая модель пекарни

Одностраничная интерактивная HTML-модель, построенная по формулам листа «Финмодель» исходной Google-таблицы.

Модель исправляет обнаруженные проблемы листа «Сценарный анализ»: сдвиг ссылок на драйверы, пустую ячейку ставки налога, отсутствующие дельты аренды и коммунальных услуг, а также использование даты старта вместо горизонта планирования.

Откройте `index.html` в браузере. Внешние зависимости и сборка не требуются.
